# Security Policy

## Supported versions

Until 1.0, only the latest tagged release is supported.

## Reporting a vulnerability

Do not publish security-sensitive details in a public issue. Use the private
security-reporting route configured on the repository once it is public.

## Data handling

LeanLocal is designed to avoid collecting identifying information. Reports
must not intentionally include usernames, hostnames, serial numbers, network
addresses, credentials, personal files, or browser/account data.

## Release rule

A release is blocked if the maintainer cannot explain every collected field,
why it is necessary, and why it is safe to share by default.
