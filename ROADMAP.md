# Roadmap

## 0.1 — first public candidate

- redacted capability report
- short low-resource benchmark
- read-only dependency checks
- conservative workload guidance
- inspectable JSON support bundle
- privacy and security documentation
- standard-library test suite

## After 0.1

Priorities will be driven by reproducible user issues and low-spec hardware
testing. Likely work includes wider Linux distribution testing, clearer
machine-readable output, packaging improvements, accessibility, and additional
privacy regression tests.

## Boundaries

The project remains a small local diagnostic and capability toolkit. Expansion
into remote control, autonomous operation, workflow orchestration, credential
handling, or cloud account management is outside the project scope.
